Job summary

  • Enrichment method: ORA
  • Organism: hsapiens
  • Enrichment Categories: pathway_Reactome
  • Interesting list: a R object. ID type: entrezgene
  • The interesting list contains 416 user IDs in which 415 user IDs are unambiguously mapped to 415 unique entrezgene IDs and 1 user IDs can not be mapped to any entrezgene ID.
  • The GO Slim summary are based upon the 415 unique entrezgene IDs.
  • Among 415 unique entrezgene IDs, 381 IDs are annotated to the selected functional categories and also in the reference list, which are used for the enrichment analysis.
  • Reference list: all mapped entrezgene IDs from the selected platform genome
  • The reference list can be mapped to 61506 entrezgene IDs and 10554 IDs are annotated to the selected functional categories that are used as the reference for the enrichment analysis.

Parameters for the enrichment analysis:

  • Minimum number of IDs in the category: 10
  • Maximum number of IDs in the category: 500
  • FDR Method: BH
  • Significance Level: FDR < 0.2

Based on the above parameters, 129 categories are identified as enriched categories, in which 20 most significant categories and represetatives in the reduced sets are shown in this report. All significant categories can be downloaded from the 'Result Download' link.

GO Slim summary for the user uploaded IDs

Each Biological Process, Cellular Component and Molecular Function category is represented by a red, blue and green bar, repectively.

The height of the bar represents the number of IDs in the user list and also in the category.
